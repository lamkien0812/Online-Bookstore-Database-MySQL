# Demo Script

Recommended 2-4 minute demo:

1. Run `sql/01_schema.sql`, `02_seed_data.sql`, and `03_objects.sql` in MySQL Workbench.
2. Show the eight tables and explain PK/FK relationships.
3. Run Q01 to demonstrate filtering, sorting and LIMIT.
4. Run Q02 and Q03 to demonstrate INNER JOIN and LEFT JOIN.
5. Run Q04 for aggregate revenue statistics.
6. Run Q07 for the window-function ranking.
7. Run Q11 for pagination and Q12 for the CTE report.
8. Run `CALL sp_create_order(1, 2, 2);` to show the stored procedure.
9. Insert a successful payment for the created order and show that its status becomes PAID through the trigger.
10. Run `EXPLAIN` from `sql/05_bonus.sql` and show the ERD.
